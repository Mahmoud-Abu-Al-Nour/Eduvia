# Phase 0 — Initialization

## Goal
Establish the foundational infrastructure, runtime environment, containerization, and repository layout for Eduvia.

## Scope
- Docker Compose setup for PostgreSQL 16, Qdrant, backend, and frontend.
- Backend project scaffolding with `pyproject.toml`, FastAPI, Uvicorn, and base configuration.
- Frontend initialization with React 19, Vite, TypeScript, and Tailwind CSS.
- Health check endpoints and initial testing harnesses.

## Key Outcomes
- Development environment runs via `docker compose up`.
- Backend imports verified with `uv` virtual environment.
- Initial project guidelines and architecture documentation established in `docs/`.
