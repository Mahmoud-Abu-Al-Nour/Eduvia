# Product Decisions

Canonical product design decisions agreed upon for Eduvia.

---

### Decision 01: Web Application First for MVP
- **Decision**: Target modern responsive desktop/tablet web browsers first.
- **Rationale**: Primary usage takes place in school computer labs, classroom Chromebooks, and teacher workstations.

### Decision 02: Non-Authenticated Learner Model in MVP
- **Decision**: Learners do not manage traditional email/password credentials.
- **Rationale**: Accessibility barrier reduction; teachers orchestrate sessions.

### Decision 03: Five Initial Activity Types
- **Decision**: Constrain MVP activity types to Matching, MCQ, Ordering, Visual Identification, and Drag-and-Drop.
- **Rationale**: Broad pedagogical coverage with low cognitive friction and high tactile accessibility.

### Decision 04: Text-to-Speech as a Core Primitive
- **Decision**: Audio narration of instructions is built into the MVP roadmap.
- **Rationale**: Essential for learners with dyslexia, visual impairment, or processing delays.
