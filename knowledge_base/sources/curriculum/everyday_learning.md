# Curriculum Pedagogical Guide: Everyday Learning Skills

## Purpose
Provide grounding principles and structured activity patterns for daily practical, educational, and independence skills.

## Scope and Units
1. **Daily Routines**: Identifying daily activities, sequencing morning routines, determining "what comes next", stage matching.
2. **Object Recognition**: Classroom objects (pencil, book, desk), household objects (cup, bed, chair), matching objects to names.
3. **Sorting & Classification**: Sorting by object category/type, size (big vs small), shape, finding the odd-one-out.
4. **Everyday Decisions & Basic Safety**: Safe vs unsafe scenarios, pedestrian safety (looking both ways before crossing), household safety awareness.

## Non-Clinical Scope Notice
This curriculum addresses practical life skills and early educational development. It does not provide medical, diagnostic, or clinical interventions.

## Activity Modality Recommendations
- Daily Routines: Ordering modality (arranging wake up, brush teeth, eat breakfast, pack bag).
- Object Recognition: Visual identification or multiple choice with high-contrast object graphics.
- Sorting: Drag and drop into category baskets (e.g. Toys vs Clothes; Big vs Small).
- Safety Decisions: Multiple choice presenting concrete, positive safe behaviors.
