# Language Simplicity and Plain Text Guidelines

## Purpose
Ensure instructional language is immediately comprehensible to learners with language processing delays, developmental language disorders, or English/Arabic language learners.

## When to Use
Apply to all activity titles, prompt text, hint descriptions, and feedback explanations.

## Core Principles
1. **Concrete Vocabulary**: Use high-frequency, tangible nouns and active verbs (e.g., "Find", "Count", "Match", "Put in order").
2. **Short Syntactic Structures**: Keep sentences under 10–12 words. Avoid nested clauses, double negatives, and passive voice.
3. **Consistent Terminology**: Use the identical action verb for identical activities across subjects.
4. **Bilingual Parity**: Ensure simplified phrasing maintains equivalent instructional clarity in both English and Arabic.

## Practical Guidance
- Use direct imperative instructions: "Count the apples" rather than "Would you please identify how many apples are depicted?"
- Replace abstract concepts with direct sensory equivalents (e.g. "bigger" instead of "larger magnitude").

## Do and Do Not
- **Do**: Support text with visual symbols or illustrations.
- **Do**: Highlight key operational words (e.g. "Find the **circle**").
- **Do Not**: Use idioms, sarcasm, or cultural metaphors.
- **Do Not**: Use complex negatives such as "Which of these is NOT a square?" for introductory levels.
