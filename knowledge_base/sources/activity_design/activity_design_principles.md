# Activity Design Principles for Learners with Special Educational Needs

## Matching Activities

Matching activities should:
- Use clear, high-contrast images or text labels
- Present no more than 4-6 pairs at a time
- Use consistent size and spacing for all items
- Provide immediate feedback when a match is correct or incorrect
- Include audio support for item labels when appropriate

## Multiple Choice Activities

Multiple choice activities should:
- Present one clear question at a time
- Use 2-4 options (2 for beginners, 4 for advanced)
- Make distractors clearly different from the correct answer
- Use images alongside text where possible
- Avoid trick questions or ambiguous wording

## Ordering Activities

Ordering activities should:
- Use 3-5 items maximum for beginners
- Provide visual context clues (numbering, arrows)
- Use familiar sequence types (daily routines, story events)
- Allow learners to see all items before beginning
- Support drag-and-drop and click-to-select interaction modes

## Visual Identification Activities

Visual identification activities should:
- Use clear, unambiguous photographs or illustrations
- Highlight the region of interest when prompting
- Avoid cluttered or complex images
- Ensure sufficient size and contrast for visual targets
- Name objects using consistent vocabulary

## Drag and Drop Activities

Drag and drop activities should:
- Use large, easy-to-grip draggable items
- Provide clear, visually distinct drop zones
- Give feedback on both incorrect and correct placements
- Support touch and mouse/pointer interaction equally
- Allow reset without penalty to encourage exploration

## General Principles

- One task at a time — avoid cognitive overload
- Clear, simple instructions in plain language
- Immediate, specific feedback for every response
- Positive language in feedback messages
- Consistent visual layout across activity types
- Optional audio narration for all instructions and items
- Success state should be clearly celebratory
- Error state should be encouraging, not punishing
