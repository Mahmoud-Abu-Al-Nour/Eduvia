# Prompting and Fading in Special Education

## Purpose
Guide the systematic presentation and gradual reduction of instructional assistance to ensure learners acquire skills without developing prompt dependency.

## When to Use
Use when a learner is acquiring a new skill, struggles with independent initiation, or needs visual/verbal support during activity interaction.

## Core Principles
1. **Least-to-Most or Most-to-Least**: Select the prompting hierarchy based on the learner's profile.
2. **Systematic Fading**: Prompts must fade as accuracy stabilizes above 80%.
3. **Immediate Scaffolding**: Never allow repeated failure without an accessible prompt.
4. **Calm Feedback**: Praise the attempt and independent response rather than prompt reliance.

## Prompting Hierarchy
- **Visual Clue**: Highlighting, color borders, or symbol indicators.
- **Verbal Nudge**: A single clear question or sentence redirecting attention.
- **Model / Demonstration**: Showing how the first step or item works.
- **Direct Guidance**: Explicitly indicating the target action.

## Practical Guidance
- Graded hints in activities should follow this exact sequence:
  - Hint 1: Focus attention on relevant features (e.g., "Look at the number of red apples").
  - Hint 2: Provide a specific operational clue (e.g., "Count each apple one by one: 1, 2, 3...").
  - Hint 3: Direct guidance (e.g., "There are 3 apples. Select the number 3").

## Do and Do Not
- **Do**: Keep hints short, positive, and concrete.
- **Do**: Allow sufficient processing time before presenting subsequent hints.
- **Do Not**: Give multi-step verbal prompts that overload working memory.
- **Do Not**: Penalize a learner's mastery score solely because a Level 1 hint was viewed.

## Accessibility Considerations
Ensure hints are presented with high contrast, screen-reader announced via ARIA live regions, and can be dismissed without keyboard traps.
