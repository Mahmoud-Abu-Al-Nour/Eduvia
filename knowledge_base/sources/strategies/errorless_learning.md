# Errorless Learning and Error Reduction

## Purpose
Minimize opportunities for learners with severe developmental delays or memory processing difficulties to commit and reinforce errors during early instructional phases.

## When to Use
Highly effective for students who experience severe perseveration, math anxiety, or severe memory retrieval deficits where incorrect associations become hard to break.

## Core Principles
1. **Immediate Prompting**: Supply the prompt immediately with the stimulus before the learner can guess incorrectly.
2. **Delayed Prompting**: Gradually increase latency (0 sec, 1 sec, 2 sec) before presenting the prompt as competence builds.
3. **Prevention over Correction**: Preventing an incorrect response is far superior to remediating a learned mistake.
4. **Positive Framing**: Emphasize correct models rather than drawing attention to errors.

## Practical Guidance
- When introducing a new letter or number, highlight the correct target vividly while keeping distractors muted.
- In matching activities, ensure the target match is prominently positioned initially before introducing counter-distractors.

## Do and Do Not
- **Do**: Praise accurate responses warmly.
- **Do**: Quickly reset and provide immediate guidance if an incorrect choice begins.
- **Do Not**: Use jarring error buzzer sounds or harsh red X markings that trigger stress.
- **Do Not**: Allow prolonged trial-and-error guessing.
