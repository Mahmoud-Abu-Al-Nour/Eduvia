# Task Analysis and Chaining

## Purpose
Deconstruct complex educational and behavioral skills into discrete, observable, and sequential components that learners with cognitive or developmental challenges can master step-by-step.

## When to Use
Use when teaching multi-step routines, sequencing activities, mathematical problem solving, or complex literacy tasks.

## Core Principles
1. **Discrete Steps**: Break actions into atomic units that can be executed independently.
2. **Forward or Backward Chaining**:
   - Forward Chaining: Master Step 1 first, then Step 2, up to the final step.
   - Backward Chaining: Provide full support until the final step, allowing the learner to experience task completion.
3. **Clear Transition Indicators**: Visual or auditory markers indicating step completion.
4. **Cognitive Calm**: Reduce cognitive load by presenting one step at a time.

## Practical Guidance
- For ordering activities, limit sequence length based on learner working memory (2–3 items for introductory levels; 4–5 items for advanced).
- For multi-step routines (such as washing hands or crossing the street), present steps in strict chronological order with unambiguous visual cues.

## Do and Do Not
- **Do**: Ensure each step has an unambiguous starting condition and completion signal.
- **Do**: Validate that prerequisite sub-skills (e.g., recognizing numerals before ordering them) are mastered first.
- **Do Not**: Combine two distinct cognitive tasks into a single prompt step.
- **Do Not**: Skip steps or assume intermediate mastery.

## Example
Daily Routine Task Analysis (Washing Hands):
1. Turn on water.
2. Wet hands.
3. Apply soap.
4. Rub hands together.
5. Rinse under water.
6. Dry with towel.
