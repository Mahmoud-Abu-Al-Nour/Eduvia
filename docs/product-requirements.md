# Eduvia — Product Requirements

See the full specification in the project brief.

## Summary

- Adaptive educational platform for learners with special educational needs
- Core: Same Curriculum + Personalized Delivery
- Three roles: Admin, Teacher, Learner
- Five activity types: Matching, Multiple Choice, Ordering, Visual Identification, Drag & Drop
- Five modalities tracked: Visual, Reading, Writing, Audio, Interactive

## What Eduvia Is NOT

- Not a medical diagnostic tool
- Not an autonomous AI decision maker
- Not a replacement for teachers

See architecture.md for full technical design.
